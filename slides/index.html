Problem Statement

Tourists can't assess destination quality by topic

The Information Gap
Aggregate star ratings collapse 7 distinct complaint categories into a single number
A destination rated 4/5 stars could be hiding serious safety or roads complaints beneath excellent scenery scores
Tourists booking Sri Lankan trips have no structured, per-topic evidence to assess risk before visiting
No prior published ABSA system exists for Sri Lankan tourism at this geographic scale or with measured reliability thresholds
Pontiki et al. (2014). SemEval-2014 Task 4: Aspect Based Sentiment Analysis. SemEval Workshop.
Pontiki et al. (2016). SemEval-2016 Task 5: Aspect Based Sentiment Analysis. SemEval Workshop.
Who Is Affected
International Tourists (TripAdvisor corpus)
UK 4,446 · Australia 1,990 · India 1,621 · USA 1,289 of 16,156 reviewers — exactly 1 Sri Lankan. They rely solely on aggregate scores with no topic breakdown.
Local Residents (Google Maps corpus)
Google Maps skews local. Complaints from a Sri Lankan versus a foreign tourist about the same destination can differ significantly — that contrast is itself a research finding.
SLTDA / Destination Operators
Complaint patterns are known anecdotally but not measured at district level with documented reliability. Infrastructure deficits (roads, facilities) cannot be prioritised without structured evidence.
Research Gap + Objectives

Four concrete, measurable research objectives

RO1 · Aspect Classification
Sentence-level topic labelling
Classify individual opinion units across 7 complaint categories — Safety, Cleanliness, Facilities, Roads & Access, Price & Value, Crowding, Scenery — using a multi-layer pipeline
RO2 · Evidence Thresholds (Novel)
Reliability-derived display rules
Derive minimum-opinion thresholds from a 200-bootstrap Spearman-Brown split-half study. Suppress cells below the coin-toss threshold (n<10, reliability 0.46) — not by intuition
Brown (1910); Spearman (1910). Prophecy formula.
RO3 · Geographic Intelligence
Actionable insight by district and destination
Surface complaint patterns at three levels: Sri Lanka → District → Destination → Aspect → Evidence quotes. Enable comparison across 19 of 22 districts.
RO4 · Real-Time API
Live review analysis endpoint
FastAPI /analyse endpoint: tourist submits a review, receives aspect-polarity scores with triggering words highlighted, compared against the historical 46,854-review baseline. Response <200 ms.

Solution Architecture · Five-Layer ML Pipeline

Raw review → structured complaint score

1
Rule Lexicon Deployed
Hand-crafted keyword lists per topic · gated triggers ("deep" + "water" + "dangerous") · veto rules prevent false matches · fully auditable — every tag points to the triggering word
↓ tagged opinion units
2
MiniLM Embedding Similarity Experimental
sentence-transformers/all-MiniLM-L6-v2 · 384-dim vectors · cosine similarity threshold 0.40, probe-calibrated on 22-item set
Reimers & Gurevych (2019). Sentence-BERT. EMNLP 2019.
↓ 57,621 weakly labelled segments
3
LR Aspect Classifier Experimental
One-vs-rest Logistic Regression per aspect · C=1.0 · class_weight="balanced" · trained on weak supervision labels — recognises paraphrases the rules miss
↓ safety precision: 0.48 → 0.867
4
Safety Classifier Deployed
Hazard word AND physical context required · "We saw monkeys very close up" → not a safety complaint · precision: 0.867 vs raw lexicon: 0.48
↓ N / P / X per tagged unit
5
Twitter-RoBERTa Sentiment Deployed
cardiffnlp/twitter-roberta-base-sentiment-latest · 3-class softmax · aspect-prepended input for per-aspect ABSA · domain correction for tourism words
Barbieri et al. (2020). TweetEval. EMNLP Findings 2020.

Novel Contribution · Reliability-Derived Evidence Thresholds

Display thresholds derived from data, not intuition

Spearman-Brown Split-Half Reliability
200 bootstrap replications per destination-aspect cell. Each splits the opinions in half and asks: do both halves agree on the complaint rate? Prior systems chose "show if n ≥ 5" by intuition. Here the threshold is measured.
Brown (1910); Spearman (1910). Prophecy formula for split-half reliability.
n opinionsReliabilityDisagrees byShown as
2 – 9 0.462 26.0 pp Suppressed
10 – 19 0.749 15.5 pp Low confidence
20 – 49 0.809 11.7 pp Published
50 – 99 0.893 6.8 pp Published
100+ 0.960 3.7 pp High confidence

What makes this novel
Prior complaint mining systems chose display thresholds by intuition. Here thresholds are derived from measured reliability and validated by a permutation null — the threshold is a research finding, not a design choice. 271 suppressed cells are reported honestly as a coverage statistic, not hidden.
External validity check
Complaint rates cross-checked against TripAdvisor bubble scores (independent scale, different reviewer population). Inverse correlation confirms rates measure something real.

Key Findings (Reported, Not Buried)
Dual-Reader Finding
Same system, same data, two readers: macro accuracy 0.636 vs 0.747 — an 11 pp swing. Accuracy is a property of the task and reader, not just the system. Both figures are published.
Self-Labelling Trap
Roads & Access F1: 0.914 on self-labelled sets. Against human labels: 0.635. Drop of 0.279 — self-labels were flattering the component they were meant to justify.

Professional · Legal · Social · Security · Ethical Issues

Specific mitigations — not generic slides

Professional
No personal data collected — token-based ownership (SHA-256 hash, never stored in plain text) allows correction rights without accounts. Write endpoint refuses to start if bound to 0.0.0.0 simultaneously with a database URL.
Legal
Raw CSVs excluded from repo — "the two review corpora are third-party scrapes this project has no right to redistribute." Pre-built dashboard IS committed so pages open immediately. Wikipedia photos used (not Google Places Photos which require API key travel with user data).
Social
TripAdvisor corpus: 99.99% non-Sri Lankan reviewers. Audience bias explicitly disclosed in methodology, not hidden. Google Maps (local-skewing) included specifically to capture local perspective alongside international. Local/international divergence is a finding, not a flaw.
Security
Hard-coded server refusal: if SUBMISSIONS_DATABASE_URL is set AND binding to 0.0.0.0, server refuses to start — prevents publishing a write endpoint into thesis data. MAX_REQUESTS_PER_RUN=200 prevents accidental billing spikes against Google Places API. Rate-limited Reddit scrape (1 req/sec) with honest User-Agent string.
Ethical
"Not right?" button on every tag — contributor corrections accepted and stored. Test asserts they can never enter published accuracy figures (tests/test_contributor_separation.py) without a deliberate annotation pass. Withdraw-not-delete: removed reviews persist in database so downstream counts stay auditable.
Non-Functional Requirements (Measured)
Performance
<200 ms /analyse response for real-time review analysis · Pipeline refresh: ~15 seconds from raw corpus (cached)
Reliability
50+ automated tests covering pipeline, API parity, media separation, contributor separation, accuracy provenance. Preflight check refuses to start with stale dashboard.
Maintainability
Every hyperparameter has a comment explaining why that value was chosen. Nothing is a magic number. MIN_WORDS=4 (derived from 17% short-review corpus analysis).
Scalability / Portability
Single-file self-contained dashboard (3.8 MB) opens from a USB stick — no server required. SQLite locally; PostgreSQL URL for hosted deployment. Gateway on single port eliminates CORS.
